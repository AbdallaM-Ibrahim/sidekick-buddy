# Sidekick Buddy

## Summary

Money tracking app that will track daily expenses and periodic ones. will track all kind of assets like money gold stock etc.
should be engaging app that encourages me to open it every day every time I have some assets to track or just for the small in-day spending

## Intention

easy to use but still full of features with good UX and Main dashboard to have the important info and stared sections where it can be designed for example by row or column. and how many items can each occupy at a time
the app is mainly designed to help individuals and can be customizable to match all needs and preferences of the user like tracking his family expenses or children goals
should be a customizable application with some initial values for enums but can be expanded by usage
should be very typescript efficient for easy human development by a developer
should be divided into feature based folders and clean architecture structure
all features should be expandable as a customizable use case which some actions can be grouped if logically viable and can be separated or embedded only when needed and available as an action

## Features

- Assets: Money, Gold, Stock etc. as generic not hard coded values those vales can be the starter set if no set
- Transactions: Any flow of assets like buying new gold ingot, paying for coffee, buying a house, lending mony to a friend, Saving certificate, buying new phone etc.
- Periodic Transactions: Internet Bill, Application subscription (can be yearly and shows in monthly calculates), loan (and doesn't need to be monthly payment and be quarterly or custom period), paycheck (which can be delayed than its usual occurrence so it needs notification and confirmation). with comments and attachments for tracking purposes
- Goals: Saving to buy a House goal, go into Summer Trip or buying new laptop. can have reach text attachments to fully describe the goal
- Accounts: Cash Wallets, Bank Accounts, Cards (Credit/Debit/Prepaid), Investments (stocks, Crypto, Gold) where can be quantitative and value based not just numeric
